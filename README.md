# Daylight — Habit Tracker

The first interface for the Habit Tracker project: a responsive daily dashboard with sample habits, working completion toggles, a progress ring, and a weekly snapshot.

## Open it

Open `index.html` in a modern browser. No install or build step is required. The Google Fonts connection is optional; the page falls back to system sans-serif fonts if it is unavailable.

## Current scope

- Dashboard layout for desktop and mobile
- Today's date from the local device clock
- Five example habits with interactive checkboxes
- Today's completed count and progress ring update when toggled
- Sample weekly chart and summary
- Add a habit with an optional note; habits and completion states persist in this browser
- Row-menu buttons still show a “coming soon” message

## Next implementation step

Next: track completion history by day so the weekly chart reflects real activity. Keep the app useful without accounts or AI.
